# Inspirational Message Generator

A simple JavaScript program that generates a random inspirational message each time it is run.

The program combines a random motivational greeting with an inspirational quote and its author to create a different message each time.

## Features

- Generates a random motivational greeting
- Selects a random inspirational quote
- Displays the correct author for each quote
- Personalises the message with a user's name
- Produces a new combination each time the program runs

## Technologies Used

- JavaScript
- Node.js
- Git
- GitHub
- VS Code

## How to Run

1. Make sure Node.js is installed.
2. Open the project folder in your terminal.
3. Run:

```bash
node script.js

Each time the program runs, a new random message will be generated.
